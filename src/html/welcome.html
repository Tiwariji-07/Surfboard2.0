Surfboard AI

Your AI-powered assistant for WaveMaker Studio

What You Can Do

  • Context-aware code assistance tailored to your WaveMaker page
  • Inline completions directly in the Studio code editor
  • Chat with AI grounded in WaveMaker docs and best practices
  • Automatic log capture and AI-powered error analysis
  • Search across project files, widgets, and bindings

Getting Started

  1. Configure your LiteLLM connection

    You need a LiteLLM API key and a running proxy.

    The default proxy address is http://localhost:4000. If Studio is served over HTTPS, your LiteLLM endpoint must also use HTTPS.
  2. Set your API key and models

    Click the extension icon in Chrome and enter your key, base URL, and model aliases.

  3. Open WaveMaker Studio

    Navigate to your project and press Ctrl + \ to open the Surfboard sidebar.

Keyboard Shortcuts

  • Toggle sidebar Ctrl + \
  • Send message Ctrl + Enter
  • Dismiss suggestion Esc
